# 🚗 ParkEasy — Real-Time Smart Parking & Hosting Platform

ParkEasy is a full-stack, cross-platform smart parking reservation and space hosting platform powered by **Jetpack Compose (Android)**, **HTML5/Tailwind Web App**, and **Firebase Cloud Firestore**.

## ✨ Features

- ⚡ **Real-Time Cross-Platform Sync**: Synchronizes parking space listings, bookings, and provider earnings in real-time across Web and Mobile using Firebase Cloud Firestore (`parkeasy-20d83`).
- 📍 **GPS Coordinate Pinning & Navigation**: Precise host GPS location pinning and direct Turn-by-Turn Google Maps navigation (`google.navigation:q=lat,lng`).
- 💳 **Realistic UPI Payment Flow**: Integrated Google Pay, PhonePe, Paytm, and BHIM UPI selectors with instant Digital QR Pass generation.
- 🛡️ **Security Guard Gate Check-In**: Live QR pass verification and guard status simulation.
- 🚀 **High-Performance Jetpack Compose UI**: Optimized 60-120 FPS scrolling layout with Coil memory caching and stable item keys.
